프린터가 "오프라인"으로 뜰 때 점검하는 순서

프린터는 켜져 있는데 컴퓨터에서만 오프라인으로 보이는 상황을 해결하는 순서입니다. 드라이버를 다시 깔기 전에 확인할 것들부터 정리했습니다.

  4. 3. 인쇄 대기열을 비웁니다
  5. 4. 기본 프린터가 엉뚱한 것으로 바뀌었는지 봅니다

프린터에는 불이 들어와 있고 종이도 들어 있는데, 컴퓨터에서는 회색으로 "오프라인"이라고 뜹니다. 급하게 인쇄할 게 있을 때 이 상황이 오면 답답합니다.

대부분은 드라이버를 다시 설치할 필요 없이 해결됩니다. 아래 순서대로 가면 보통 3~4번 안에서 끝납니다.

0. 30초 안에 되는 것부터

시간이 없다면 이것부터 해보세요. 체감상 절반 정도는 여기서 해결됩니다.

  1. 프린터 전원을 끄고, 전원 케이블을 뽑고, 30초 기다렸다가 다시 연결합니다.
  2. 프린터가 완전히 켜질 때까지(준비 완료 표시가 뜰 때까지) 기다립니다.
  3. 컴퓨터를 다시 시작합니다. 종료 후 켜기가 아니라 "다시 시작"으로 하세요.

전원 케이블까지 뽑는 이유는 프린터 안쪽 메모리를 완전히 비우기 위해서입니다. 버튼만 껐다 켜면 대기 상태만 바뀌고 오류가 그대로 남는 기종이 많습니다.

1. 연결 방식부터 확인합니다

프린터가 컴퓨터와 어떻게 연결되어 있는지에 따라 확인할 곳이 다릅니다.

USB로 연결한 경우

  • 케이블을 다른 USB 포트에 꽂아봅니다. 특히 본체 앞면이 아닌 뒷면 포트로요.
  • USB 허브를 거치고 있다면 빼고 본체에 직접 연결합니다. 전력 부족으로 인식이 끊기는 일이 흔합니다.
  • 케이블이 오래됐다면 다른 케이블로 바꿔봅니다.

와이파이로 연결한 경우

  • 프린터 화면에서 네트워크 상태를 확인합니다. 와이파이 아이콘이 떠 있나요?
  • 컴퓨터와 프린터가 같은 와이파이에 있는지 확인합니다. 이게 생각보다 자주 원인입니다. 공유기가 2.4GHz와 5GHz를 다른 이름으로 쓰는 경우, 프린터는 2.4GHz에만 붙고 노트북은 5GHz에 붙어 서로 못 봅니다.
  • 게스트 와이파이에 연결되어 있으면 안 됩니다. 게스트망은 기기 간 통신을 막습니다.
  • 공유기를 새로 바꿨거나 비밀번호를 변경했다면, 프린터도 다시 연결해야 합니다.

프린터 IP를 확인해 두세요

대부분의 프린터는 조작부에서 네트워크 설정 → 네트워크 구성 페이지 인쇄를 실행하면 현재 IP 주소가 적힌 종이를 뽑아줍니다. 그 IP를 브라우저 주소창에 입력했을 때 프린터 설정 화면이 열린다면, 네트워크 연결 자체는 정상이라는 뜻입니다.

2. "프린터 오프라인 상태로 사용" 체크를 풉니다

윈도우가 스스로 오프라인 모드로 바꿔놓고 안 풀어주는 경우가 있습니다.

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너로 들어갑니다.
  2. 해당 프린터를 클릭한 뒤 인쇄 대기열 열기를 누릅니다.
  3. 창 위쪽 메뉴에서 프린터를 클릭합니다.
  4. 프린터를 오프라인 상태로 사용 항목에 체크가 되어 있으면 클릭해서 해제합니다.
  5. 같은 메뉴의 일시 중지도 체크되어 있으면 해제합니다.

3. 인쇄 대기열을 비웁니다

실패한 인쇄 작업 하나가 걸려서 그 뒤로 아무것도 안 나가는 경우가 아주 흔합니다.

같은 인쇄 대기열 창에서 프린터 → 모든 문서 취소를 누릅니다. 그래도 목록에서 안 사라지고 "삭제 중"에서 멈춰 있다면 서비스를 다시 시작해야 합니다.

  1. Windows 키 + R → services.msc 입력 → 엔터
  2. 목록에서 Print Spooler를 찾습니다.
  3. 우클릭 → 중지
  4. 그 상태에서 Windows 키 + R → 아래 경로를 붙여 넣고 엔터
%windir%\System32\spool\PRINTERS
  1. 폴더 안의 파일을 모두 삭제합니다. (관리자 권한 확인 창이 뜨면 계속)
  2. 다시 services.msc로 돌아가 Print Spooler를 우클릭 → 시작

이 폴더에는 대기 중인 인쇄 작업만 들어 있어서 지워도 안전합니다.

4. 기본 프린터가 엉뚱한 것으로 바뀌었는지 봅니다

윈도우에는 마지막에 사용한 프린터를 기본으로 설정하는 옵션이 있습니다. 이게 켜져 있으면 PDF 저장 도구 등이 기본 프린터로 바뀌어 있곤 합니다.

설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 맨 아래로 내려가 Windows에서 기본 프린터 관리 항목을 끄고, 원하는 프린터를 눌러 기본값으로 설정을 지정하세요.

5. 프린터를 지웠다가 다시 추가합니다

여기까지 안 되면 등록 정보가 꼬인 것입니다.

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너에서 해당 프린터 선택
  2. 제거를 누릅니다.
  3. 프린터 전원을 껐다 켠 뒤, 같은 화면에서 장치 추가를 누릅니다.
  4. 목록에 나타나면 선택해서 추가합니다.

목록에 안 뜬다면 원하는 프린터가 목록에 없습니다를 누르고, 와이파이 프린터라면 TCP/IP 주소를 사용하여 프린터 추가를 골라 2단계에서 확인한 IP 주소를 직접 입력하면 됩니다.

IP 주소가 계속 바뀐다면

공유기가 프린터에 매번 다른 IP를 주면 며칠에 한 번씩 같은 문제가 반복됩니다. 프린터 설정에서 IP를 고정(수동)으로 지정하거나, 공유기 관리 페이지에서 해당 기기에 고정 IP 할당(DHCP 예약)을 걸어두면 재발을 막을 수 있습니다.

6. 드라이버 문제일 때

윈도우를 크게 업데이트한 뒤부터 안 된다면 드라이버가 원인일 수 있습니다.

  • 제조사(HP, 캐논, 엡손, 삼성/HP, 브라더 등) 홈페이지에서 모델명 + 윈도우 11용 드라이버를 직접 받아 설치하세요. 윈도우가 자동으로 잡아준 범용 드라이버보다 안정적입니다.
  • 오래된 프린터라 윈도우 11용 드라이버가 없다면, 윈도우 10용을 받아 설치 파일을 우클릭 → 속성 → 호환성 → 호환 모드로 이 프로그램 실행으로 시도해 볼 수 있습니다.

그래도 안 될 때 확인할 것

  • 다른 기기에서는 인쇄가 되나요? 스마트폰에서 인쇄가 된다면 프린터는 정상이고 컴퓨터 쪽 문제입니다. 반대로 스마트폰에서도 안 되면 프린터나 네트워크 문제입니다.
  • 회사나 학교 PC인가요? 보안 정책이나 프린터 서버 설정 때문일 수 있으니 전산 담당자에게 문의하는 편이 빠릅니다.
  • 잉크나 토너가 완전히 비었나요? 일부 기종은 소모품이 없으면 아예 오프라인으로 표시됩니다.
  • 프린터 화면에 오류 코드가 떠 있나요? 그 코드를 모델명과 함께 검색하면 용지 걸림이나 헤드 문제 같은 구체적인 원인이 나옵니다.

정리

  1. 프린터 전원 케이블을 뽑았다가 다시 연결 + PC 다시 시작
  2. 같은 와이파이에 있는지 확인 (2.4GHz / 5GHz 주의)
  3. "오프라인 상태로 사용" 체크 해제
  4. 인쇄 대기열 비우고 Print Spooler 재시작
  5. 프린터 삭제 후 다시 추가 (필요하면 IP 직접 입력)
  6. 제조사 드라이버 재설치

경험상 1번과 4번에서 가장 많이 해결됩니다. 급할 때는 스마트폰 앱이나 USB에 담아 인쇄하는 방법으로 우회하고, 차분히 시간이 있을 때 위 순서대로 잡으시길 권합니다.
