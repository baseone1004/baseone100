새 폰으로 데이터 옮기기 — 옮기기 전에 준비할 것부터

기기 변경 전에 미리 챙겨야 할 것과, 안드로이드·아이폰 조합별 이전 방법을 정리했습니다. 자동으로 안 옮겨지는 카카오톡 대화와 인증 앱이 핵심입니다.

2026-08-27 작성 ·2026-09-05 확인 ·읽는 데 약 7분

  2. 조합별 이전 방법
  3. 옮긴 뒤에 확인할 것
  4. 옛 폰 정리하기
  5. 정리

새 폰을 받으면 대리점에서 대충 옮겨주기도 하고, 마법사를 따라 하면 대부분 넘어옵니다. 문제는 자동으로 안 넘어가는 것들입니다. 그걸 모르고 옛 폰을 초기화해 버리면 되돌릴 방법이 없습니다.

이 글은 이전 방법보다 미리 챙길 것에 더 무게를 두었습니다.

옮기기 전 체크리스트

옛 폰을 반납하거나 초기화하기 전에 반드시 확인하세요.

1. 카카오톡 대화 백업 (가장 많이 놓칩니다)

카카오톡 대화는 계정을 옮긴다고 따라오지 않습니다. 별도로 백업해야 합니다.

카카오톡 → 더보기(⋯) → 설정 → 채팅 → 대화 백업에서 백업합니다. 이때 정한 비밀번호를 반드시 기억하세요. 잊으면 복원할 수 없고 재발급도 안 됩니다.

안드로이드 ↔ 아이폰 사이는 대화 이전이 안 됩니다

카카오톡 대화 백업·복원은 같은 운영체제 사이에서만 됩니다. 안드로이드에서 아이폰으로(또는 그 반대로) 바꾸시면 대화 내용은 넘어가지 않습니다. 꼭 남겨야 하는 대화가 있다면 대화방별 내보내기(대화 내용 내보내기) 기능으로 텍스트나 메일로 따로 저장해 두세요.

2. 인증 앱과 은행 인증서

이게 두 번째로 많이 놓치는 부분입니다. 옛 폰을 초기화하면 계정에 못 들어가는 상황이 생깁니다.

  • 구글 OTP(Authenticator) — 요즘 버전은 구글 계정으로 동기화가 가능합니다. 앱을 열어 동기화가 켜져 있는지 확인하세요. 꺼져 있다면 켜두거나, 각 서비스에서 백업 코드를 미리 받아 종이에 적어두세요.
  • 은행·증권 앱의 인증서 — 대부분 클라우드 보관 또는 재발급이 필요합니다. 새 폰에서 인증서를 못 받으면 앱 로그인이 막히므로, 옛 폰이 살아 있을 때 처리하세요.
  • PASS, 네이버·카카오 인증서 — 새 기기에서 본인 확인을 다시 하면 됩니다. 다만 본인 확인에 문자 수신이 필요하므로 유심을 옮긴 뒤에 진행해야 합니다.

3. 그 밖에

  • 사진과 동영상이 백업됐는지 눈으로 확인 (사진 백업 방법)
  • 메모 앱 — 기본 메모는 계정 동기화 여부를 확인하세요.
  • 알람, 통화 기록, 문자 — 문자는 대개 옮겨지지만 일부 조합에서는 빠집니다.
  • 게임 계정 연동 — 게스트 계정으로 하던 게임은 반드시 계정을 연동해 두세요. 기기를 바꾸면 진행 상황이 사라집니다.
  • 음악·구독 서비스 로그인 정보

조합별 이전 방법

안드로이드 → 안드로이드

가장 간단합니다. 새 폰을 처음 켜면 나오는 설정 마법사에서 안내대로 따라가면 됩니다.

같은 제조사(예: 갤럭시 → 갤럭시)라면 Smart Switch를 쓰는 편이 가장 많이 옮겨집니다. 케이블로 두 기기를 연결하거나 무선으로 진행할 수 있고, 홈 화면 배치와 설정까지 넘어옵니다.

제조사가 다르다면 설정 마법사의 구글 계정 백업 복원을 이용합니다. 앱, 연락처, 사진(백업된 것), 일부 설정이 넘어옵니다.

케이블 연결이 훨씬 빠릅니다

무선으로 하면 사진이 많을 때 몇 시간이 걸립니다. 두 기기를 USB 케이블로 직접 연결하면 훨씬 빠르고 중간에 끊기지 않습니다. 대부분 새 폰 상자에 필요한 젠더가 들어 있습니다.

아이폰 → 아이폰

새 아이폰을 켜고 옛 아이폰을 옆에 두면 빠른 시작 화면이 뜹니다. 안내대로 따라가면 앱, 설정, 사진까지 거의 전부 그대로 넘어옵니다.

두 기기를 나란히 두고 전원과 Wi-Fi를 연결한 채 진행하세요. 용량에 따라 30분~2시간 정도 걸립니다.

안드로이드 → 아이폰

애플의 iOS로 전송(Move to iOS) 앱을 안드로이드 폰에 설치해서 진행합니다.

  1. 새 아이폰을 켜고 설정 화면에서 "Android에서 데이터 이동"을 선택합니다.
  2. 화면에 나오는 코드를 안드로이드 폰의 "iOS로 전송" 앱에 입력합니다.
  3. 옮길 항목을 선택하고 기다립니다.

연락처, 문자, 사진, 캘린더, 일부 앱 정보가 넘어옵니다. 카카오톡 대화와 유료 앱은 넘어오지 않습니다.

아이폰 → 안드로이드

갤럭시로 옮기신다면 Smart Switch가 아이폰도 지원합니다. 케이블(라이트닝 또는 USB-C)로 직접 연결하거나, 아이클라우드 백업에서 가져올 수 있습니다.

옮기기 전에 아이폰에서 iMessage를 꼭 끄세요. 설정 → 메시지 → iMessage를 끄지 않으면, 다른 아이폰 사용자가 보낸 문자가 안드로이드 폰에 도착하지 않습니다. 이미 폰을 처분했다면 애플의 등록 해제 페이지에서 해제할 수 있습니다.

옮긴 뒤에 확인할 것

새 폰이 다 세팅됐다고 옛 폰을 바로 초기화하지 마세요. 최소 일주일은 옛 폰을 그대로 두고 아래를 확인하는 것이 안전합니다.

  1. 사진 개수가 비슷한지 (갤러리 하단이나 앨범 정보에서 확인)
  2. 카카오톡 대화가 복원됐는지
  3. 은행·증권 앱에 로그인이 되는지
  4. 자주 쓰는 앱에 모두 로그인되어 있는지
  5. 알람이 제대로 설정되어 있는지 (놓치면 다음 날 지각합니다)
  6. 문자와 연락처가 다 있는지

옛 폰 정리하기

확인이 끝났다면 안전하게 정리합니다. 순서가 중요합니다.

  1. 계정을 먼저 로그아웃합니다. - 아이폰: 설정 → (내 이름) → 맨 아래 로그아웃. 이걸 안 하면 "나의 찾기" 잠금이 걸려 다음 사용자가 쓸 수 없습니다. - 안드로이드: 설정 → 계정에서 구글 계정을 삭제합니다. 마찬가지로 초기화 보호가 걸립니다.
  2. 유심(SIM)과 SD 카드를 뺍니다.
  3. 초기화합니다. - 아이폰: 설정 → 일반 → 전송 또는 iPhone 재설정 → 모든 콘텐츠 및 설정 지우기 - 안드로이드: 설정 → 일반 → 초기화 → 공장 초기화

계정 로그아웃 없이 초기화하면 곤란해집니다

로그아웃하지 않고 초기화하면 활성화 잠금이 남아, 중고로 팔거나 가족에게 물려줄 때 원래 계정 비밀번호가 없으면 사용할 수 없는 기기가 됩니다. 반드시 로그아웃이 먼저입니다.

중고로 판매하실 거라면 초기화 후 아무 계정이나 넣고 설정을 한 번 마쳐보세요. 잠금이 안 걸려 있는지 확인하는 가장 확실한 방법입니다.

정리

  1. 옮기기 전에 카카오톡 대화 백업과 인증 앱·인증서부터 챙기기
  2. 안드로이드↔아이폰 사이는 카톡 대화가 안 넘어감을 기억
  3. 케이블로 연결하면 훨씬 빠르고 안정적
  4. 새 폰 확인이 끝날 때까지 일주일은 옛 폰을 남겨두기
  5. 초기화 전에 계정 로그아웃 먼저
