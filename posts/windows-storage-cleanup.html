윈도우 저장 공간이 부족할 때, 안전하게 용량 확보하는 순서

C 드라이브가 빨갛게 변했을 때 어디부터 지워야 할지 정리했습니다. 되돌릴 수 있는 방법부터 순서대로, 건드리면 안 되는 폴더까지 함께 설명합니다.

2026-07-02 작성 ·2026-08-28 확인 ·읽는 데 약 7분

이 글의 순서

  1. 먼저 무엇이 용량을 차지하는지 봅니다
  2. 1단계 — 임시 파일 정리 (가장 안전하고 효과가 큽니다)
  3. 2단계 — 저장 공간 센서를 켜둡니다
  4. 3단계 — 안 쓰는 앱 정리
  5. 4단계 — 최대 절전 모드 파일 (하드 용량이 작을 때)
  6. 5단계 — 시스템 복원 용량 줄이기
  7. 6단계 — 원드라이브 파일 온디맨드
  8. 7단계 — 큰 파일을 직접 찾아냅니다

C 드라이브 막대가 빨갛게 변하면 마음이 급해집니다. 그런데 이때 검색해서 나오는 "이 폴더를 지우세요" 같은 글을 그대로 따라 하면 윈도우가 부팅되지 않는 상황까지 갈 수 있습니다.

이 글은 되돌리기 쉬운 방법부터 순서대로 정리했습니다. 위에서부터 차례로 해보시고, 필요한 만큼 확보되면 거기서 멈추면 됩니다.

먼저 무엇이 용량을 차지하는지 봅니다

지우기 전에 어디에 얼마나 쓰고 있는지부터 확인해야 헛수고를 안 합니다.

  1. Windows 키 + I를 눌러 설정을 엽니다.
  2. 시스템 → 저장소로 들어갑니다.
  3. 잠시 기다리면 앱, 임시 파일, 문서, 사진 등 항목별 사용량이 막대로 나옵니다.
  4. 아래쪽 저장 공간 사용량 더 보기를 누르면 더 자세히 볼 수 있습니다.

여기서 유난히 큰 항목이 하나 보인다면, 그 항목만 해결해도 끝나는 경우가 많습니다.

1단계 — 임시 파일 정리 (가장 안전하고 효과가 큽니다)

설정 → 시스템 → 저장소 → 임시 파일로 들어갑니다. 목록에서 체크한 항목만 지워지므로, 아래 항목 위주로 선택하세요.

  • Windows 업데이트 정리 — 업데이트 설치 후 남은 백업본. 보통 몇 GB씩 나옵니다.
  • 배달 최적화 파일 — 다른 PC와 업데이트를 주고받으려고 받아둔 조각. 지워도 됩니다.
  • 휴지통 — 안에 든 파일이 정말 필요 없는지 먼저 확인하세요.
  • 썸네일 — 미리보기 이미지 캐시. 지워도 다시 만들어집니다.
  • 이전 Windows 설치(Windows.old) — 대형 업데이트 후 남는 이전 버전. 20GB 이상 나올 때도 있습니다.

Windows.old를 지우기 전에

이 폴더를 지우면 이전 윈도우 버전으로 되돌리기가 불가능해집니다. 업데이트 후 프로그램이 잘 돌아가는지 며칠 써보고 지우세요. 지우지 않아도 보통 10일 뒤에 자동으로 삭제됩니다.

다운로드 항목은 기본으로 체크가 안 되어 있는데, 여기에는 직접 받은 파일이 들어 있으니 목록에서 체크하지 말고 탐색기로 직접 열어서 확인하고 지우는 편이 안전합니다.

2단계 — 저장 공간 센서를 켜둡니다

앞으로 같은 일이 반복되지 않게 자동 정리를 켜두는 단계입니다.

설정 → 시스템 → 저장소 → 저장 공간 센서를 켜고 들어가면, 휴지통에 며칠 이상 있던 파일과 열어보지 않은 다운로드 파일을 자동으로 지우도록 설정할 수 있습니다.

다운로드 폴더 자동 삭제는 "안 함"으로 두시길 권합니다. 받아둔 설치 파일이나 문서가 소리 없이 사라지면 곤란한 경우가 생깁니다. 휴지통 30일 정도만 켜두면 충분합니다.

3단계 — 안 쓰는 앱 정리

설정 → 앱 → 설치된 앱으로 들어가서 정렬 기준을 크기순으로 바꿉니다. 위쪽에 올라온 것 중 기억도 안 나는 프로그램이 있다면 지울 후보입니다.

게임 런처(스팀, 에픽 등)를 쓰신다면 여기보다 런처 안에서 게임별 용량을 확인하는 편이 정확합니다. 게임 하나가 100GB를 넘기는 일이 흔합니다.

4단계 — 최대 절전 모드 파일 (하드 용량이 작을 때)

윈도우는 C:\hiberfil.sys라는 숨김 파일에 메모리 내용을 통째로 저장해 둡니다. 크기는 설치된 메모리 용량의 40% 안팎이라, 16GB 메모리라면 6GB 남짓을 차지합니다.

최대 절전 모드를 안 쓰신다면 꺼서 이 파일을 없앨 수 있습니다.

  1. 시작 버튼을 우클릭 → 터미널(관리자) 또는 명령 프롬프트(관리자)를 엽니다.
  2. 아래 명령을 입력합니다.
powercfg /hibernate off

되돌리려면 powercfg /hibernate on을 입력하면 됩니다.

알아두실 점

이 설정을 끄면 윈도우의 빠른 시작 기능도 함께 꺼집니다. 부팅이 몇 초 느려질 수 있으니, 노트북을 자주 덮어두고 쓰시면 그냥 켜두는 편이 낫습니다.

5단계 — 시스템 복원 용량 줄이기

복원 지점은 문제가 생겼을 때 되돌리는 안전장치라 끄지는 마시고, 쓰는 용량만 줄입니다.

  1. Windows 키 + R → sysdm.cpl 입력 → 엔터
  2. 시스템 보호 탭 → C 드라이브 선택 → 구성
  3. 아래쪽 최대 사용량 막대를 3~5% 정도로 내리고 확인

이미 쌓인 오래된 복원 지점은 같은 화면의 삭제 버튼으로 정리할 수 있습니다. 단, 삭제하면 최근 복원 지점까지 모두 사라지니 지금 PC가 정상 작동할 때만 하세요.

6단계 — 원드라이브 파일 온디맨드

원드라이브를 쓰신다면 클라우드에만 두고 PC 용량은 비울 수 있습니다.

탐색기에서 원드라이브 폴더나 하위 폴더를 우클릭 → 여유 공간 확보를 누르면, 파일 목록은 그대로 보이면서 실제 데이터는 클라우드로 올라갑니다. 필요할 때 더블클릭하면 그때 내려받습니다. 아이콘이 구름 모양이면 클라우드에만 있는 상태입니다.

7단계 — 큰 파일을 직접 찾아냅니다

여기까지 해도 부족하다면, 어디에 큰 파일이 숨어 있는지 눈으로 봐야 합니다. WizTree나 TreeSize Free 같은 무료 도구를 쓰면 폴더별 용량을 크기순으로 보여줍니다.

자주 발견되는 것들입니다.

위치내용
다운로드 폴더예전에 받은 설치 파일, 압축 파일
바탕 화면임시로 옮겨두고 잊은 영상·이미지
문서\카카오톡 받은 파일대화방에서 받은 사진과 동영상
AppData\Local\Temp프로그램이 남긴 임시 파일
영상 편집·게임 폴더프로젝트 캐시, 렌더링 결과물

절대 하면 안 되는 것

용량 확보 글에 종종 나오지만, 실제로는 위험하거나 의미 없는 방법들입니다.

  • C:\Windows\WinSxS 폴더를 직접 지우기 — 시스템 파일 저장소입니다. 지우면 업데이트와 기능 복구가 깨집니다. 이 폴더는 반드시 위의 Windows 업데이트 정리 기능을 통해서만 줄여야 합니다.
  • System32 안의 파일 삭제 — 윈도우가 부팅되지 않습니다.
  • "레지스트리 청소기"류 프로그램 — 확보되는 용량은 거의 없고, 잘못 지우면 프로그램이 실행되지 않습니다.
  • 가상 메모리(페이지 파일) 완전 해제 — 몇 GB는 벌지만 메모리가 부족할 때 프로그램이 강제 종료됩니다. 건드리지 않는 편이 낫습니다.

그래도 부족하다면

위 방법을 다 해도 여유가 안 생긴다면 디스크 자체가 작은 경우입니다. 요즘 윈도우 11은 시스템만 40~60GB를 쓰기 때문에 128GB SSD로는 사실상 빠듯합니다.

  • 데스크톱이라면 SSD를 하나 더 추가하고 게임과 사진을 그쪽으로 옮기는 편이 가장 확실합니다.
  • 노트북이라 증설이 어렵다면 외장 SSD나 클라우드로 사진·영상을 옮기세요.
  • 사진 백업은 사진 백업 방법 비교 글을 참고하시면 됩니다.
