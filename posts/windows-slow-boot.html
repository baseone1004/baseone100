컴퓨터 부팅이 느려졌을 때 순서대로 확인하는 방법

전원을 켜고 한참 기다리게 되는 PC의 원인을 찾는 순서입니다. 시작 프로그램, 빠른 시작, 저장 장치, 업데이트까지 어디를 먼저 봐야 하는지 정리했습니다.

2026-07-09 작성 ·2026-08-30 확인 ·읽는 데 약 7분

이 글의 순서

  1. 먼저 어느 구간이 느린지 나눕니다
  2. 1. 시작 프로그램부터 정리합니다
  3. 2. 백그라운드에서 도는 것을 봅니다
  4. 3. 윈도우 업데이트를 끝까지 마칩니다
  5. 4. 빠른 시작 설정을 점검합니다
  6. 5. 저장 장치가 HDD인지 확인합니다
  7. 6. 시스템 파일에 문제가 없는지 검사
  8. 이건 하지 마세요
  9. 정리

"예전엔 안 이랬는데"라는 말이 나오는 대표적인 순간이 부팅입니다. 전원 버튼을 누르고 커피를 타 와야 바탕 화면이 뜨는 상태라면, 원인은 대개 몇 가지 안에 있습니다.

무작정 최적화 프로그램을 설치하기 전에, 아래 순서대로 확인해 보세요. 어느 구간이 느린지부터 나눠 보는 것이 핵심입니다.

먼저 어느 구간이 느린지 나눕니다

부팅은 크게 두 구간으로 나뉩니다.

  1. 전원 버튼 → 제조사 로고 → 윈도우 로고가 뜨기까지 (하드웨어와 BIOS 구간)
  2. 윈도우 로고 → 로그인 → 바탕 화면이 정상적으로 반응하기까지 (윈도우 구간)

1번이 길면 하드웨어나 BIOS 설정 문제, 2번이 길면 윈도우 안쪽 문제입니다. 대부분은 2번이며, 특히 바탕 화면은 떴는데 클릭이 한참 안 먹는 증상이 가장 흔합니다.

작업 관리자에서 대략적인 수치도 볼 수 있습니다. Ctrl + Shift + Esc → 시작 프로그램 앱 탭 오른쪽 위에 마지막 BIOS 시간이 표시됩니다. 이 값이 10초를 넘어가면 BIOS 구간을 의심할 만합니다. 보통은 3~10초 사이입니다.

1. 시작 프로그램부터 정리합니다

가장 효과가 크고 되돌리기도 쉬운 단계입니다.

  1. Ctrl + Shift + Esc로 작업 관리자를 엽니다.
  2. 왼쪽에서 시작 프로그램 앱을 선택합니다.
  3. 시작 시 영향 열을 눌러 정렬합니다.

여기서 높음으로 표시된 것 중 지금 당장 필요 없는 것을 우클릭해 사용 안 함으로 바꿉니다. 프로그램이 삭제되는 게 아니라 자동 실행만 멈추는 것이라 언제든 되돌릴 수 있습니다.

대체로 꺼도 되는 것들

  • 각종 업데이트 확인 도구 (~ Update Helper, ~ Updater)
  • 프린터·스캐너 제조사의 모니터 프로그램
  • 게임 런처 (스팀, 에픽, 배틀넷 — 필요할 때 직접 켜면 됩니다)
  • 잘 안 쓰는 메신저, 클라우드 동기화 앱
  • 그래픽카드 제조사의 부가 프로그램 (드라이버 자체와는 별개입니다)

끄면 안 되는 것들

  • 백신·보안 프로그램
  • 터치패드, 오디오 드라이버 관련 항목
  • 노트북 제조사의 전원 관리 프로그램
  • 이름을 봐도 무슨 프로그램인지 전혀 모르겠는 항목 (검색해 보고 판단하세요)

이름이 낯설 때

항목을 우클릭 → 파일 위치 열기를 누르면 어떤 프로그램인지 폴더 이름으로 확인할 수 있습니다. 그래도 모르겠으면 그냥 두세요. 하나 꺼서 얻는 시간보다 잘못 껐을 때 생기는 문제가 큽니다.

2. 백그라운드에서 도는 것을 봅니다

바탕 화면이 뜬 뒤에도 몇 분간 버벅인다면, 로그인 직후 뭔가가 열심히 돌고 있다는 뜻입니다.

작업 관리자 → 프로세스 탭에서 디스크와 CPU 열을 눌러 정렬해 보세요. 부팅 직후 자주 100%를 차지하는 것들입니다.

이름정체대처
Antimalware Service Executable윈도우 보안(디펜더) 검사정상. 몇 분 뒤 내려갑니다
Windows 모듈 설치 관리자업데이트 설치 중업데이트를 끝까지 마치세요
Microsoft Compatibility Telemetry사용 정보 수집잠시 후 내려갑니다
SearchIndexer파일 검색 색인정상. 처음 며칠만 높습니다
백신 프로그램 이름실시간 검사두 개 이상 깔려 있는지 확인

여기서 백신이 두 개 이상 설치되어 있다면 반드시 하나만 남기세요. 서로를 검사하면서 부팅이 극단적으로 느려지는 대표적인 원인입니다.

3. 윈도우 업데이트를 끝까지 마칩니다

"업데이트 대기 중" 상태로 몇 주씩 둔 PC는 부팅할 때마다 준비 작업을 반복합니다.

설정 → Windows 업데이트에서 남은 업데이트를 모두 설치하고, 다시 시작이 필요합니다라고 뜨면 미루지 말고 재부팅하세요. 한 번 제대로 마치고 나면 그다음 부팅부터 눈에 띄게 빨라지는 경우가 많습니다.

4. 빠른 시작 설정을 점검합니다

윈도우에는 빠른 시작이라는 기능이 있습니다. 종료할 때 완전히 끄지 않고 시스템 상태를 파일로 저장해 두었다가 다음에 그대로 불러오는 방식입니다. 보통은 부팅을 빠르게 해줍니다.

그런데 드라이버가 오래됐거나 듀얼 부팅을 쓰는 환경에서는 오히려 문제를 일으킵니다. "종료했다 켜면 이상한데 재시작하면 멀쩡하다"는 증상이 있으면 이 기능을 의심하세요.

  1. Windows 키 + R → powercfg.cpl 입력 → 엔터
  2. 왼쪽 전원 단추 작동 설정
  3. 현재 사용할 수 없는 설정 변경을 클릭
  4. 아래 빠른 시작 켜기 체크를 해제하고 저장

끄면 부팅이 몇 초 느려지는 대신 매번 깨끗한 상태로 시작합니다. 증상이 사라진다면 그래픽·칩셋 드라이버를 최신으로 업데이트한 뒤 다시 켜보세요.

참고로 다시 시작은 빠른 시작의 영향을 받지 않고 항상 완전히 새로 부팅합니다. 문제가 생겼을 때 "종료 후 켜기"가 아니라 "다시 시작"을 권하는 이유가 여기 있습니다.

5. 저장 장치가 HDD인지 확인합니다

여기까지 해도 답이 없다면 하드웨어를 봐야 합니다. 부팅 속도에 가장 큰 영향을 주는 건 CPU도 메모리도 아니고 저장 장치입니다.

작업 관리자 → 성능 탭 → 왼쪽에서 디스크를 선택하면 오른쪽 위에 종류가 나옵니다.

  • SSD로 표시되는데 느리다 → 위의 소프트웨어 문제일 가능성이 큽니다.
  • HDD로 표시된다 → 여기가 원인입니다. 요즘 윈도우는 HDD에서 부팅에만 1~3분이 걸립니다.

10년 가까이 된 PC라도 SSD로 바꾸면 부팅과 프로그램 실행 체감이 완전히 달라집니다. 부품 하나로 얻는 효과로는 가장 확실한 방법입니다.

6. 시스템 파일에 문제가 없는지 검사

특별한 이유 없이 갑자기 느려졌다면 시스템 파일 손상을 확인해 봅니다. 시작 버튼 우클릭 → 터미널(관리자)에서 순서대로 실행하세요.

sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth

각각 5~20분 정도 걸립니다. 손상된 파일이 있으면 자동으로 복구합니다. 이 명령은 파일을 지우지 않으므로 안전합니다.

이건 하지 마세요

  • "부팅 속도 향상" 최적화 프로그램 설치 — 대부분 위의 작업을 대신해 주는 척하면서 자기 자신을 시작 프로그램에 등록합니다. 오히려 느려집니다.
  • msconfig에서 서비스 전체 사용 안 함 — 어떤 게 꺼졌는지 추적이 안 되고 네트워크나 소리가 안 나오는 등 엉뚱한 곳에서 문제가 터집니다.
  • 레지스트리 값 임의 수정 — 부팅 시간이 줄어든다는 값들은 대부분 근거가 없습니다.

정리

  1. 시작 프로그램에서 필요 없는 것 끄기 (가장 먼저)
  2. 백신이 두 개 이상 깔려 있는지 확인
  3. 밀린 윈도우 업데이트 끝까지 설치
  4. 증상이 이상하면 빠른 시작 꺼보기
  5. 디스크가 HDD면 SSD 교체 고려
  6. sfc /scannow로 시스템 파일 점검

이 순서대로 하면 대부분 1~3번에서 해결됩니다. 그래도 느리다면 블루스크린이나 오류 로그가 남아 있는지 확인해 볼 차례입니다.
