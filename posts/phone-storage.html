스마트폰 저장 공간 정리, 뭘 지워야 안전한가

저장 공간 부족 알림이 뜰 때 무엇부터 지워야 할지 정리했습니다. 캐시와 데이터의 차이, 카카오톡 정리법, 지우면 안 되는 것까지 다룹니다.

"저장 공간이 부족합니다" 알림이 뜨면 사진부터 지우게 됩니다. 그런데 사진을 몇백 장 지워도 몇 GB밖에 안 줄어드는 경우가 많습니다. 정작 용량을 먹고 있는 건 다른 곳인데 엉뚱한 데를 파고 있는 것입니다.

무엇부터 봐야 하는지 순서대로 정리했습니다.

먼저 어디에 쓰고 있는지 봅니다

  • 안드로이드: 설정 → 디바이스 케어(또는 배터리 및 디바이스 케어) → 저장공간
  • 아이폰: 설정 → 일반 → iPhone 저장 공간

여기서 앱, 사진, 미디어, 시스템 등 항목별 용량이 나옵니다. 아이폰은 앱을 용량순으로 정렬해 보여주고, 각 앱을 눌러 "앱 크기"와 "문서 및 데이터"를 따로 볼 수 있어서 특히 확인하기 편합니다.

보통 순위는 이렇게 나옵니다.

  1. 사진·동영상
  2. 메신저 앱의 "데이터" (카카오톡이 압도적)
  3. 게임
  4. 유튜브·넷플릭스 등의 오프라인 저장본

1. 캐시와 데이터를 구분하세요

정리하기 전에 이 차이를 알아야 실수를 안 합니다.

캐시(임시 파일)데이터
내용다시 받을 수 있는 임시 사본로그인 정보, 대화 기록, 설정
지우면앱이 조금 느려졌다가 회복로그아웃되고 기록이 사라질 수 있음
안전한가안전합니다위험합니다

안드로이드에서 설정 → 앱 → (앱 선택) → 저장공간에 들어가면 캐시 삭제와 데이터 삭제 버튼이 따로 있습니다.

"데이터 삭제"는 초기화입니다

캐시 삭제는 언제든 해도 되지만, 데이터 삭제는 그 앱을 새로 설치한 상태로 되돌립니다. 카카오톡에서 누르면 대화 내용이 전부 사라집니다. 반드시 "캐시 삭제"인지 확인하세요.

아이폰에는 캐시만 지우는 기능이 따로 없습니다. 대신 앱 지우기(Offload)를 쓰면 앱만 지우고 데이터는 남겨두었다가, 다시 설치했을 때 그대로 이어서 쓸 수 있습니다.

2. 카카오톡부터 정리합니다 (효과가 가장 큽니다)

한국에서 저장 공간을 가장 많이 차지하는 앱은 대개 카카오톡입니다. 단톡방에서 오간 사진과 동영상이 계속 쌓이기 때문입니다.

카카오톡 앱 안에서 정리합니다.

  1. 카카오톡 → 더보기(⋯) → 오른쪽 위 설정(톱니바퀴)
  2. 앱 관리 → 저장공간 관리
  3. 여기서 캐시 데이터 삭제, 음악 캐시 데이터 삭제, 동영상 캐시 데이터 삭제를 실행합니다.

이것만으로 몇 GB가 확보되는 경우가 흔합니다. 대화 내용은 지워지지 않습니다.

이어서 앞으로 안 쌓이게 설정합니다.

  • 설정 → 채팅 → 사진 화질을 "일반"으로
  • 설정 → 채팅 → 미디어 자동 다운로드를 "안 함" 또는 "Wi-Fi에서만"으로

3. 사진과 동영상은 백업 후 정리

사진이 가장 큰 항목이라면, 지우기 전에 먼저 백업이 되어 있는지 확인해야 합니다.

구글 포토를 쓰신다면 이렇게 하면 안전합니다.

  1. 구글 포토 앱에서 백업이 "백업 완료" 상태인지 확인합니다.
  2. 프로필 아이콘 → 저장용량 확보 (또는 "기기에서 삭제")를 누릅니다.
  3. 이미 백업된 사진만 기기에서 지워집니다.

아이폰은 설정 → 사진에서 iPhone 저장 공간 최적화를 켜면 원본은 iCloud에 두고 기기에는 작은 사본만 남깁니다.

백업 확인 없이 지우지 마세요

"클라우드에 있겠지" 하고 지웠는데 백업이 몇 달 전에 멈춰 있던 경우가 정말 많습니다. 지우기 전에 클라우드 앱을 열어 최근 날짜 사진이 보이는지 눈으로 확인하세요. 자세한 방법은 사진 백업 방법 비교에 정리했습니다.

동영상은 개수는 적어도 용량이 큽니다. 갤러리에서 동영상만 모아 보기로 들어가 용량이 큰 순서로 정렬해 확인해 보세요. 한두 개만 옮겨도 몇 GB가 나오는 경우가 있습니다.

4. 안 쓰는 앱 정리

안드로이드: 플레이스토어 → 프로필 → 앱 및 기기 관리 → 관리 탭에서 정렬을 "사용한 적 없음"이나 "크기순"으로 바꾸면 후보가 바로 나옵니다.

아이폰: 설정 → 일반 → iPhone 저장 공간에서 미사용 앱 정리를 켜두면 오래 안 쓴 앱이 자동으로 정리(데이터는 유지)됩니다.

게임은 특히 확인해 보세요. 한 번 하고 안 하는 게임이 5GB씩 차지하고 있는 경우가 흔합니다.

5. 다운로드 폴더와 오프라인 저장본

잊고 지내는 곳입니다.

  • 다운로드 폴더 — 카톡에서 받은 파일, 웹에서 받은 문서가 계속 쌓입니다. "내 파일" 또는 "파일" 앱에서 다운로드 폴더를 열어 확인하세요.
  • 유튜브 오프라인 저장 — 유튜브 앱 → 보관함 → 오프라인 저장에서 확인 후 삭제
  • 넷플릭스·티빙 등의 다운로드 콘텐츠 — 각 앱의 다운로드 목록에서 정리
  • 음악 앱의 오프라인 재생 목록 — 멜론, 스포티파이 등

6. SD 카드를 쓸 수 있다면

SD 카드 슬롯이 있는 안드로이드 기기라면 사진·동영상을 옮길 수 있습니다.

다만 알아두실 점이 있습니다.

  • SD 카드는 내장 저장소보다 느리고 고장 확률이 높습니다. 유일한 사본을 두지 마세요.
  • 앱 자체를 SD 카드로 옮기면 앱 실행이 느려질 수 있습니다.
  • 카드를 뺐다 끼우다 보면 인식 오류가 나기도 합니다. 중요한 자료는 클라우드에도 두세요.

이건 하지 마세요

  • "휴대폰 청소" 광고 앱 설치 — 확보되는 용량은 캐시 삭제 수준인데, 광고를 계속 띄우고 배터리와 저장 공간을 자기가 차지합니다. OS 내장 기능으로 충분합니다.
  • Android 폴더 안의 파일 임의 삭제 — 앱 데이터가 들어 있어 지우면 앱이 초기화됩니다.
  • DCIM 폴더 통째로 삭제 — 촬영한 사진이 들어 있는 폴더입니다. 백업 확인 없이 지우면 끝입니다.
  • "시스템" 항목을 줄이려는 시도 — OS 자체 용량이라 사용자가 줄일 수 없습니다. 아이폰의 "기타/시스템 데이터"는 재부팅하면 어느 정도 줄어듭니다.

그래도 부족하다면

여기까지 했는데도 매번 알림이 뜬다면 기기 용량 자체가 부족한 것입니다. 요즘 앱과 사진 용량을 생각하면 64GB 모델은 실사용에 빠듯합니다.

  • 사진과 동영상을 클라우드로 완전히 옮기는 구조를 만드세요.
  • 다음 기기를 고를 때는 최소 128GB, 사진·영상을 많이 찍으신다면 256GB를 권합니다.
  • 아이폰은 저장 공간 확장이 불가능하므로 구매할 때 결정해야 합니다.

정리

  1. 설정에서 뭐가 차지하는지 먼저 확인
  2. 카카오톡 저장공간 관리에서 캐시 삭제 (효과 가장 큼)
  3. 사진은 백업 확인 후 기기에서 삭제
  4. 안 쓰는 앱과 오프라인 저장본 정리
  5. 캐시는 지워도 되지만 데이터 삭제는 초기화임을 기억
