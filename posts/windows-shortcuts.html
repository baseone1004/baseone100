매일 쓰게 되는 윈도우 단축키만 골랐습니다

외울 만한 가치가 있는 단축키만 상황별로 정리했습니다. 창 정렬, 캡처, 이모지, 잘못 지운 파일 되살리기까지 실제로 손에 붙는 것들입니다.

단축키 목록은 검색하면 200개씩 나옵니다. 그런데 그걸 다 외우는 사람은 없습니다. 이 글은 실제로 하루에 한 번 이상 쓰게 되는 것들만 골라서, 왜 편한지와 함께 정리했습니다.

먼저 한 가지만 기억하세요. 윈도우 로고 키(이하 Win)는 장식이 아니라 운영체제 기능을 부르는 키입니다. 여기 나오는 대부분이 Win 조합입니다.

이것만 외워도 달라지는 다섯 개

단축키하는 일
Win + Shift + S화면 원하는 영역만 캡처
Win + V복사 기록에서 이전에 복사한 것 꺼내 쓰기
Win + 방향키창을 화면 반쪽/모서리에 딱 맞게 정렬
Win + D모든 창 내리고 바탕 화면 (한 번 더 누르면 복귀)
Ctrl + Shift + T방금 닫은 브라우저 탭 되살리기

이 다섯 개는 설명이 조금 더 필요합니다.

Win + Shift + S — 캡처

Print Screen으로 화면 전체를 찍고 그림판에서 자르는 과정이 통째로 사라집니다. 누르면 화면이 어두워지고 마우스로 원하는 영역을 드래그하면 됩니다. 상단 도구 모음에서 사각형·자유형·창·전체 화면을 고를 수 있고, 캡처한 이미지는 클립보드에 들어가므로 바로 Ctrl + V로 붙여 넣을 수 있습니다.

오른쪽 아래 알림을 클릭하면 편집 창이 열려 화살표나 형광펜 표시를 추가할 수 있습니다.

Win + V — 클립보드 기록

복사한 내용이 여러 개 쌓입니다. 처음 누르면 기능을 켜겠냐고 묻는데 켜면 됩니다. 표에서 값 몇 개를 옮겨 적거나, 주소와 이름을 번갈아 붙여 넣을 때 특히 편합니다.

목록에서 항목의 점 세 개를 눌러 고정해 두면 재부팅해도 남아 있습니다. 자주 쓰는 계좌번호나 주소를 고정해 두는 식으로 활용할 수 있습니다.

공용 PC에서는 끄세요

클립보드 기록에는 복사했던 내용이 그대로 남습니다. 회사나 공용 컴퓨터에서는 설정 → 시스템 → 클립보드에서 꺼두는 편이 안전합니다.

Win + 방향키 — 창 정렬

Win + ←를 누르면 지금 창이 화면 왼쪽 절반을 차지하고, 오른쪽에 나머지 창 목록이 뜹니다. 거기서 하나 고르면 좌우로 나란히 배치됩니다. 자료를 보면서 문서를 쓸 때 필수입니다.

  • Win + ↑ : 창 최대화
  • Win + ↓ : 창 축소, 한 번 더 누르면 최소화
  • Win + ← → ↑ ↓ 조합 : 화면 1/4 크기로 모서리에 배치

윈도우 11에서는 창의 최대화 버튼 위에 마우스를 올리고 있으면 레이아웃 선택지가 나타납니다. 3분할, 좌우 비대칭 분할 등을 마우스로 고를 수 있어 이쪽이 더 편할 때도 있습니다.

창과 프로그램 다루기

단축키하는 일
Alt + Tab창 전환 (계속 누른 채 방향키로 선택)
Win + Tab작업 보기 — 열린 창 전체를 한눈에
Win + Ctrl + D새 가상 데스크톱 만들기
Win + Ctrl + ← →가상 데스크톱 사이 이동
Alt + F4현재 창 닫기 (바탕 화면에서 누르면 종료 메뉴)
Win + 숫자작업 표시줄 n번째 아이콘 실행
Ctrl + Shift + Esc작업 관리자 바로 열기

Win + 숫자는 의외로 유용합니다. 작업 표시줄 왼쪽부터 1번이므로, 브라우저를 1번에 고정해 두면 어디서든 Win + 1로 부를 수 있습니다.

가상 데스크톱은 업무용과 개인용 화면을 나눌 때 씁니다. 창을 닫지 않고 통째로 다른 화면으로 넘어가므로, 회의 중에 화면 공유할 때 특히 요긴합니다.

파일 탐색기에서

단축키하는 일
Win + E파일 탐색기 열기
Ctrl + Shift + N새 폴더 만들기
F2이름 바꾸기
Alt + Enter선택한 파일의 속성 보기
Ctrl + Z실행 취소 — 방금 지우거나 옮긴 것을 되돌립니다
Shift + Delete휴지통을 거치지 않고 완전 삭제
Alt + ↑상위 폴더로

Ctrl + Z가 탐색기에서도 동작한다는 걸 모르는 분이 많습니다. 파일을 실수로 다른 폴더에 떨어뜨렸거나 이름을 잘못 바꿨을 때, 당황하지 말고 바로 누르세요.

반대로 Shift + Delete는 휴지통에도 안 남습니다. 습관적으로 쓰지 마세요.

여러 파일 이름을 한꺼번에 바꾸고 싶다면, 파일들을 모두 선택한 뒤 F2를 누르고 이름을 입력하면 사진 (1), 사진 (2) 식으로 일괄 변경됩니다.

글 쓸 때

단축키하는 일
Win + . (마침표)이모지·기호 입력창
Ctrl + Shift + V서식 없이 붙여넣기
Ctrl + ← →단어 단위로 커서 이동
Ctrl + Shift + ← →단어 단위로 선택
Home / End줄 맨 앞 / 맨 뒤로
Ctrl + Backspace앞 단어 통째로 지우기

Ctrl + Shift + V는 웹에서 복사한 글을 붙여 넣을 때 배경색과 글꼴이 딸려 오는 문제를 없애줍니다. 문서 작성이 잦다면 이 하나만으로도 시간이 꽤 절약됩니다.

Win + .은 이모지뿐 아니라 특수문자와 한자도 있습니다. ※나 → 같은 기호를 찾아 헤맬 필요가 없어집니다.

급할 때 쓰는 것

단축키하는 일
Win + L즉시 화면 잠금
Win + I설정 열기
Win + R실행 창 (명령어 직접 입력)
Win + X시작 버튼 우클릭 메뉴 (장치 관리자, 터미널 등)
Win + P외부 모니터·빔프로젝터 연결 방식 선택
Win + Ctrl + Shift + B화면이 멈췄을 때 그래픽 드라이버 재시작

Win + L은 자리를 비울 때 습관을 들여두면 좋습니다. 로그아웃이 아니라 잠금이라 하던 작업이 그대로 유지됩니다.

Win + P는 발표 직전에 화면이 안 나올 때 가장 먼저 눌러볼 조합입니다. "복제"와 "확장" 중 상황에 맞는 것을 고르면 대부분 해결됩니다.

Win + Ctrl + Shift + B는 잘 안 알려진 응급 조치입니다. 화면이 검게 멈추거나 깨져 보일 때 누르면 화면이 한 번 깜빡이면서 그래픽 드라이버만 다시 시작합니다. 열려 있던 프로그램은 그대로 유지되므로 재부팅 전에 먼저 시도해 보세요.

외우는 요령

한 번에 다 외우려 하면 하나도 안 남습니다. 이렇게 해보세요.

  1. 이번 주에 딱 두 개만 정합니다. Win + Shift + S와 Win + 방향키를 추천합니다.
  2. 마우스로 하던 그 동작이 나올 때 일부러 손을 멈추고 단축키를 씁니다.
  3. 손에 붙으면(보통 3~4일) 다음 두 개를 고릅니다.

이렇게 한 달이면 열 개 정도가 자연스럽게 남습니다. 전부 외우는 것보다 자주 쓰는 몇 개가 몸에 붙는 편이 훨씬 실속 있습니다.
